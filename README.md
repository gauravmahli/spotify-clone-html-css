# 🎵 Spotify Clone

A **Spotify-inspired music player UI** built using **HTML5 and CSS3**. This project recreates the visual layout of Spotify's web player as a frontend practice project.


## ✨ Features

* 🎧 Spotify-inspired dark-themed interface
* 🏠 Home and Search navigation
* 📚 Your Library section
* 🎵 Recently Played section
* 🔥 Trending music section
* 📊 Featured Charts section
* 🎶 Bottom music player interface
* ⏯️ Playback controls UI
* 🔊 Volume control UI
* 🎨 Custom CSS styling
* 📱 Basic responsive behavior

## 🛠️ Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Styling and layout
* **CSS Flexbox** – Page and component layouts
* **Font Awesome** – Icons
* **Google Fonts** – Montserrat font

## 🎯 Purpose

This project was created to practice:

## 🚧 Current Limitations

This is currently a **static frontend UI**.

It does not include:

* Actual music playback
* Functional play/pause controls
* Working search functionality
* User authentication
* Spotify API integration
* Dynamic playlists
